# Changelog

Floppy's releases, newest first. Versions follow
[Semantic Versioning](https://semver.org/); see "Versions and releases" in the
README for how a release is cut.

## 0.1.0

The first versioned Floppy release. Earlier builds report their version as
`dev`; from this release on, Settings → About and `/api/v1/info/` report the
release tag, or the tag plus the commits since it.

- CineTrack v2 is the only web theme.
- Supports the CineTrack Android app's background bootstrap jobs, which
  CineTrack 0.99.79 and later use for a large first sync.
